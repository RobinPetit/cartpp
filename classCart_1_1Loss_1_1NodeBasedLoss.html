Detailed Description

template<std::floating_point FloatType, class LossType>
class Cart::Loss::NodeBasedLoss< FloatType, LossType >

Abstract wrapper for losses to be used during the construction of a regression/classification tree.

The idea to avoid having a method compute(const Array<Float>& y, const Array<Float>& yhat) (or more precisely compute(const Array<Float>& y, Float yhat) for CART) to compute the loss but rather to keep an intermediate state that is updated when needed, and from which the actual value can be efficiently computed.

The class must implement some methods (including compute, augment and diminish) that implement the required behaviour of each loss function and updated state.

For all loss classes, we use the following notations:

\begin{eqnarray*} W &=& \sum_{i=1}^nw_i \\ \hat\pi(y, w) &=& \frac{1}{W}\sum_{i=1}^nw_iy_i, \end{eqnarray*}

where \(n\) is the number of observations added to the loss (see size()).

Detailed Description

template<std::floating_point FloatType, class LossType>
class Cart::Loss::impl::NonNegativeIntegerLoss< FloatType, LossType >

Generic abstract class for loss when \(y \in [0, N] \cap \mathbb{Z}\).

Keeps the sums (i) \(\displaystyle\sum_{i \in \mathcal{I}_y}w_i\) for each integer value of \(y\), (ii) \(\displaystyle\sum_{i=1}^nw_i\), (iii) \(\displaystyle\sum_{i=1}^ny_i\) and (iv) \(\displaystyle\sum_{i=1}^nw_iy_i\).

Here, \(\mathcal{I}_y\) is the set of indices \(i \in [1, n] \cap \mathbb{Z}\) such that \(y_i = y\).

Only compute() remains to be implemented for concrete classes. See PoissonDeviance and NegativeBinomialDeviance.
